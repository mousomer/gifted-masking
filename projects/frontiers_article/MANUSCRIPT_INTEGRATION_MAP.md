# Paragraph-Level Manuscript Integration Map

## Purpose and identifiers

This Stage 1 map assigns every prose paragraph in the four long-form Markdown
sources to the planned Frontiers article architecture. It is an integration
contract, not permission to paste the chapters together. Stage 3 will convert
the destinations below into the final paragraph outline and enforce the RDS
word budget.

Source IDs combine a short file code with the paragraph's starting line:

- `LR-L###`: `LITERATURE_REVIEW_CHAPTER.md`;
- `MC-L###`: `MODEL_CASCADE_CHAPTER.md`;
- `RB-L###`: `RESULTS_BY_FINDING_CHAPTER.md`;
- `DC-L###`: `DISCUSSION_CHAPTER.md`.

Current manuscript IDs (`P###`) refer to nonempty paragraphs extracted from
`gifted_masking_frontiers_original_research_assertive_revision.docx`. They are
anchors for Stage 1 only; paragraph numbers will change when the manuscript is
rewritten. The current manuscript is 4,071 main-text words, while the RDS
targets approximately 8,000-9,000 words, so the map expects selective
expansion from the sources rather than compression of the current DOCX alone.

Disposition values:

- **Keep:** retain the paragraph's distinct argumentative or methodological
  function, after editing;
- **Compress:** merge its substance with named neighboring material;
- **Move:** retain the substance in a different article section;
- **Evidence-held:** retain only as bounded wording until the named Stage 2
  evidence gate passes;
- **Citation pool:** retain the reference only if it is cited by the final
  integrated prose.
