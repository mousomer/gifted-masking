```text

```

Granularity:

- One row per matched child-level unit for M0, M1, M2, M3, and M4
  condition-contrast checks where model outputs are per child.
- One row per matched ramp-grid unit for current M4 ramp-up/ramp-down path
  checks.

## M2 Optimal-Policy Benchmark

Path:

```text
results/summaries/m2_optimal_policy_benchmark.csv
```

This artifact compares selected M2 parameter cells against a value-iteration
solution for the maintained three-state MDP. It includes the static M0
comparator, M2 optimal state actions, Bellman residual, learned final-window
state-conditional mask probabilities where available, neutral-state policy
value, and neutral-state regret.

## M2 Lock-In Region Map

Paths:

```text
results/summaries/m2_lock_in_region_map.csv
results/summaries/m2_lock_in_region_thresholds.csv
results/summaries/m2_regime_refined_thresholds.csv
results/summaries/m2_learner_parameter_sensitivity.csv
results/summaries/m2_optimal_regime_sensitivity.csv
```

The cell-level map stores a deterministic `(p, eta)` sweep under explicitly
recorded learner settings. Each row classifies the cell using:

- static M0 neutral optimum;
- optimal M2 neutral action from value iteration;
- learned final-window neutral action from simulation;
- neutral-state regret when the empirical policy is evaluable.

The threshold summary compresses the grid into the first `p` value where static
authenticity becomes optimal, the first `p` value where dynamic M2
authenticity becomes optimal, the first `p` value where the learned policy
becomes neutral-state authentic, and the `p` ranges classified as optimal or
learned lock-in.

The refined threshold artifact estimates default dynamic thresholds by binary
search. The learner sensitivity artifact varies `alpha`, `tau`, `lambda`, `q0`,
and learner `gamma` at selected cells. The optimal-regime sensitivity artifact
varies dynamic/environment parameters including `gamma`, `r2`, `b2`, `delta`,
and `eta` to identify where optimal-policy masking becomes possible.

## Manifest

Path:

```text
results/manifests/robustness_full.json
```

Required top-level keys:

```text
run_id
command
working_directory
git
environment
simulation
artifacts
verification
timestamps
```

The manifest must include:

- explicit git commit or unavailable reason;
- package versions;
- master seed;
- bootstrap seed;
- seed strategy;
- RNG stream strategy;
- parameter grids;
- `n_per_cell`;
- `T`;
- final-window fraction;
- artifact paths;
- code/config hash.

`scripts/validate_manifest.py` validates this schema and fails on missing
required fields.

## Report

Path:

```text
results/reports/robustness_full_report.md
```

The report is human-readable and summarizes headline estimates. Machine checks
should use CSV artifacts rather than parsing the markdown report.
