# Workspace governance adoption

This software-only adoption uses the immutable workspace/policy-kit distribution
1.4.0 and runtime 0.7.0. The published repository baseline supplies project
authorities: ARCHITECTURE.md and README.md. Existing instructions and model,
reward, parameter, RNG, scientific-evidence and execution gates retain their owners.

The declared repository verifier remains ./scripts/verify.sh with all original
checks. Its governance hook runs before product checks. The tools runtime
profile certifies only governance machinery; it never certifies the application
dependencies, scientific results, model quality or publication claims.

Normal execution uses the inherited existing workspace interpreter through an
approved local overlay or GOVERNANCE_PYTHON. Local machine configuration and
private evidence are ignored and must never be committed.

Unit tests isolate M2 output roots and E06 source/Git/freshness fixtures. They
use the APIs already present in the published baseline. No later research
branch, scientific source revision, real record, checkpoint, derived result,
figure, manuscript or data file is imported by this adoption. Standard and
qualification execution remain refused under the existing product contract.

Fresh software checks and immutable release identity establish only their stated
scope. They do not refresh or seal scientific evidence packages.
